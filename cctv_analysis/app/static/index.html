AI model providers

      
Vision-language models used for event descriptions, unreadable plates and Ask the AI in the Forensic Studio. They are tried top to bottom: when one fails, the next answers. Types: openai = any OpenAI-compatible server (Ollama, LM Studio, vLLM, llama.cpp, OpenAI); nvidia = NVIDIA NIM / integrate.api.nvidia.com (address may stay empty); transformers = a Hugging Face model run on this PC. With no provider the built-in Qwen3-VL-2B runs on this PC. Test sends a picture with a number and checks the model reads it.
